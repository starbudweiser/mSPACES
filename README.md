# mSPACES

[![Listed on OpenMacApps](https://openmacapps.com/badge.svg)](https://openmacapps.com/apps/mspaces/) [![Latest release](https://img.shields.io/github/v/release/starbudweiser/mSPACES)](https://github.com/starbudweiser/mSPACES/releases/latest) [![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

Separators for your macOS menu bar, so related items sit together in groups.

mSPACES is made by Starbudweiser & Claude Code (Anthropic). MIT License, © 2026 Starbudweiser. Provided as is, without warranty of any kind.

mSPACES adds separators to your macOS menu bar so related items sit together in groups. Click a separator and choose "New Separator" to add another one; hold Command and drag a separator to move it. Each separator can be a space, a tab, a dot, a bar or a dash. Available in English, French, Spanish and Italian, with automatic updates from GitHub releases.

## Features

- Separators in the menu bar to group related items.
- Click a separator and choose "New Separator" to add another one; hold Command and drag a separator to move it.
- Each separator can be a space, a tab, a dot, a bar or a dash.
- Automatic updates from GitHub releases.

## Install

**[Download the latest notarized release](https://github.com/starbudweiser/mSPACES/releases/latest)**, unzip it and move **mSPACES.app** to your Applications folder. Requires **macOS 13 Ventura** or later.

## Build

```bash
./build.sh
```

Requires macOS 13 or later and the Swift toolchain.

## Languages

English, French, Spanish and Italian. The app follows your Mac's preferred language automatically (English if it is none of these four).

## Français

mSPACES ajoute des séparateurs à la barre de menus de macOS pour regrouper les éléments qui vont ensemble. Cliquez sur un séparateur et choisissez « Nouveau séparateur » pour en ajouter un ; maintenez Commande et faites glisser un séparateur pour le déplacer. Chaque séparateur peut être un espace, une tabulation, un point, une barre ou un tiret.

Installation : téléchargez la [dernière version notarisée](https://github.com/starbudweiser/mSPACES/releases/latest), décompressez-la et placez **mSPACES.app** dans Applications (macOS 13 Ventura ou plus récent).

Interface en français, anglais, espagnol et italien, choisie d'après la langue du Mac (anglais sinon). Licence MIT, © 2026 Starbudweiser. Questions et bugs : [Issues GitHub](https://github.com/starbudweiser/mSPACES/issues).
